# Equashare 3.0.1 機能一覧

LaTeX数式を画像化して共有するための、Windows向けデスクトップアプリ(Tauri製)。

## 基本の数式入力
- 入力欄に1行1数式(LaTeX記法、`$$`や`\begin{align}`は不要)を書くとリアルタイムでプレビュー
- 複数行入力時は左揃えで縦に並べて1枚の画像に合成
- `\begin{nobreak}`〜`\end{nobreak}`で囲むと、コード上は複数行でも画像上では1行に結合して描画(独自拡張記法)
- 連続する行が`&`を含む場合、`\begin{align}`を書かなくても`&`の位置で縦揃え(align環境相当の見た目)
- `\text{}`で日本語を含む文章を挿入可能
- 数式は常にdisplaystyle(大きい表示)でレンダリング
- 構文エラー行は行番号を赤色表示し、その行のプレビューにのみ「Syntax Error」を表示(他行は継続表示)

## 出力・保存
- 出力形式:SVG(ベクター)/ PNG から選択
- PNGの解像度倍率、文字サイズ、余白(px)、文字色、背景色(透過可)を指定可能
- クリップボードへPNGとしてコピー(`Ctrl+Shift+C`)
- 画像ファイルとして保存(`Ctrl+S`、既定ファイル名「Equashare image」)
- LaTeXソースを`.tex`として保存(`\documentclass`等は付けず入力欄の内容そのまま、既定ファイル名「Equashare tex」)
- 初回保存先は「Equashareホームディレクトリ」、以降は直前に保存した場所を記憶
- 出力画像が大きい(高メガピクセル)場合は書き出し前に確認ダイアログを表示

## 入力補助
- ユーザーテンプレートの挿入・保存(名前を付けて保存、上書き対応)
- テンプレート管理画面(一覧・編集・削除)
- サンプル数式の挿入
- 分数・根号・上下付き・総和・積分などのスニペットボタン
- `\`入力時のサジェスト機能(LaTeXコマンド・自作`\newcommand`マクロの候補表示、上下キー選択/Tab・Enter確定/Esc閉じる)
- 選択範囲を括弧で囲むショートカット機能
- Tabキーでのスペース挿入(挿入数は設定で変更可)
- 入力欄への行番号表示

## プレビュー操作
- ズームボタンまたは`Ctrl`+マウスホイールで拡大縮小
- ドラッグでパン(視点移動)

## キーボードショートカット
- `Ctrl(⌘)+S`: 画像ファイルを保存
- `Ctrl(⌘)+Shift+C`: クリップボードにコピー
- `Ctrl(⌘)+Z`: 元に戻す
- `Ctrl(⌘)+Y` / `Ctrl(⌘)+Shift+Z`: やり直し

## レイアウト
- 入力欄と設定欄の間、編集パネルとプレビューの間をドラッグしてサイズ調整
- パネルサイズ・テーマ(ライト/ダーク)・最後に保存したフォルダを次回起動時も記憶

## 未保存管理
- 未保存の変更があるとタイトル横に●表示、ウィンドウタイトルにも反映
- アプリ終了時、未保存の変更があれば設定に応じて「確認する/自動保存する/何もしない」のいずれかで対応

## 設定(⚙)
- 言語切り替え(日本語 / English)
- UIサイズ(全体の文字・ボタンサイズ)の一括調整
- よく使う記法・保存/コピーボタンのサイズ個別調整
- サジェスト機能のON/OFF
- デフォルトテキスト(起動時のサンプル数式自動投入)のON/OFF
- Tabキーで挿入するスペース数
- 終了時の保存モード(確認する/自動保存する/保存しない)
- Equashareホームディレクトリ(画像・ソースの初期保存先)の変更
- 起動時の既定出力設定(出力形式・サイズ・色など。セッション中の変更は次回起動時にリセット)

## 日本語対応
- `\text{}`内の日本語をNoto Serif JPのアウトラインとして直接埋め込み、環境に日本語フォントが無くても正しく表示
- フォントは日本語を含む行を初めて入力したタイミングで遅延読み込み

## 対応LaTeXパッケージ(軽量化のため限定)
- `base`:基本の数式・分数・根号・添字・ギリシャ文字・行列/表環境・`\left \right`など
- `ams`:AMS-LaTeX記法(`\dfrac`、`pmatrix`、`\text`、各種矢印など)
- `boldsymbol`:数式太字
- `color`:文字色指定
- `mathtools`:amsmathの拡張記法
- `newcommand`:マクロ定義

## 動作環境
- Windows 10 / 11(64-bit)、オフラインで完結
