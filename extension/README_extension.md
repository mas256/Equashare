# Equashare (Chrome/Edge拡張機能版)

Tauriデスクトップ版から、ブラウザのサンドボックス内で完結するように移植したバージョンです。
`src/platform.ts` が、旧Rustバックエンド(クリップボード・保存・PNGラスタライズ)の代替を担っています。

## ビルド方法

```bash
npm install
npm run build
```

`dist/` フォルダに、拡張機能として読み込み可能な一式(`manifest.json`・`background.js`・`index.html`・アイコン・フォント・JS/CSS)が出力されます。

## Chrome/Edgeへの読み込み方(開発者モード)

1. `npm run build` を実行し `dist/` フォルダを作る
2. Chromeなら `chrome://extensions`、Edgeなら `edge://extensions` を開く
3. 右上の「デベロッパーモード」をON
4. 「パッケージ化されていない拡張機能を読み込む」から `dist/` フォルダを選択

読み込み後、ツールバーのEquashareアイコンをクリックするとタブでアプリが開きます(同じタブが既に開いていればそちらへフォーカスします)。

## デスクトップアプリとの連携(Native Messaging、v4.0.1〜)

Ctrl+Shift+Eを押した時、ブラウザ上で数式が選択されていれば、その数式をデスクトップ版Equashareの簡易入力ポップアップへ直接送ることができます(デスクトップアプリが起動していなければ自動的に起動します)。

- **前提条件**: デスクトップ版v5.0.0を一度起動すると、Windowsサインイン時の常駐とブラウザ連携が設定されます。未設定の場合や送信に失敗した場合は、拡張機能自身の簡易入力ポップアップにフォールバックします。
- **アプリ側のグローバルショートカットとの関係**: Chrome/Edgeが前面にある間、デスクトップ版はOS側のショートカット登録を外して拡張機能へキー入力を渡します。ブラウザ以外が前面のときはデスクトップ版の簡易表示が開きます。拡張機能側でショートカットが未割り当ての場合は `chrome://extensions/shortcuts` または `edge://extensions/shortcuts` で設定してください。
- **v5.0.0の数式取得**: MathJaxの表示ラッパー、KaTeXのレンダリングされた文字、ページ内フレームの選択に対応しています。ChatGPTの会話で表示されたKaTeX形式の式も元のTeXを取得します。

簡易表示の「編集画面へ」ボタンは入力中のテキストを保持して拡張機能の編集タブを開きます。デスクトップ版との連携がない環境では、選択テキストを使って拡張機能側の簡易表示・編集画面を利用できます。

## デスクトップ版(Tauri)との違い

| 機能 | デスクトップ版 | 拡張機能版 |
|---|---|---|
| 保存 | ホームディレクトリ記憶+ネイティブSaveダイアログ | 保存のたびにOSの「名前を付けて保存」ダイアログ(`chrome.downloads`) |
| 終了時の自動保存 | ホームディレクトリへ自動保存 | 入力のたびに`localStorage`へ下書き自動保存し、次回開いた時に復元 |
| 出力サイズの安全上限 | Rustネイティブ側で強制 | `src/platform.ts`で同じ上限値を踏襲して強制 |
| 簡易ポップアップのショートカット | 設定(⚙)内でキー入力による記録・変更・ON/OFFが可能(v4.0.1〜) | Chromeの仕様上、拡張機能はキーバインドをプログラムから書き換えられないため、設定画面には現在の割り当てを表示するのみで、変更は`chrome://extensions/shortcuts`(ブラウザ側の設定画面)へ案内する |
| Webページ上のLaTeX取得 | 非対応(デスクトップアプリのため) | ページ上でLaTeX数式(MathJax等でレンダリング済みのもの)を選択して右クリック→「Equashareで簡易表示」/「Equashareで表示」。見た目のテキストではなく、DOMから元のLaTeXソースを抽出して開く |
| 対応OS | Windows 10/11のみ | Chrome/Edgeが動く環境全般 |

## 既知の制限

- グローバルホットキーはブラウザにフォーカスがある間のみ動作します(ブラウザ非フォーカス時にも動かす「グローバル」スコープにすると`Ctrl+Shift+0〜9`しか使えないChromeの仕様上の制約のため)
- Webページ上のLaTeX取得(右クリックメニュー)は、ページ側(MathJax等)が数式への右クリックに独自メニューを表示する設定になっていると、ブラウザの標準の右クリックメニュー自体が出せず使えないことがあります。その場合はショートカット(既定 `Ctrl+Shift+E`)側でも同じ抽出ロジックを使えます。
